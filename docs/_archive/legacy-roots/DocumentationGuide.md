## Estándares de Documentación

### Formato
- Todos los documentos deben estar en Markdown
- Usar encabezados consistentes (H1 para título principal, H2 para secciones, etc.)
- Incluir tablas de contenido cuando sea apropiado
- Usar enlaces relativos entre documentos

### Estructura Recomendada
1. Título principal (H1)
2. Tabla de contenidos (cuando sea extenso)
3. Introducción o descripción
4. Secciones detalladas
5. Conclusión o resumen (cuando aplique)

### Convenciones
- Incluir fecha de creación y última modificación
- Indicar estado del documento (borrador, revisión, aprobado)
- Usar negritas para términos importantes
- Incluir ejemplos concretos
