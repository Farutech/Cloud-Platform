# 01 - DOCUMENTATION GUIDE

> **Propósito**: Establecer la estrategia de documentación para Farutech Cloud Platform  
> **Audiencia**: Todos los stakeholders (developers, architects, PMs, support, clients)  
> **Propietario**: Technical Writing Lead  
> **Última Revisión**: 2026-07-07  
> **Estado**: Actual

## Resumen

Este documento define la estrategia de documentación para Farutech Cloud Platform, estableciendo principios, estándares y procesos que aseguran que toda la documentación sea clara, completa, actualizada y útil para sus diferentes audiencias.

## Detalles

### Principios de Documentación

#### Documentación como Parte del Software
La documentación no es un entregable adicional ni una obligación administrativa. Es una parte fundamental del software que contribuye directamente al valor que entrega a los usuarios.

#### Documentación Viva y Actualizada
La documentación debe evolucionar con el software. Debe mantenerse actualizada y reflejar el estado actual del sistema, no versiones antiguas o futuras funcionalidades.

#### Documentación Orientada al Usuario
La documentación debe escribirse pensando en quién la va a leer y para qué propósito. Cada documento debe tener una audiencia clara y un propósito definido.

#### Accesibilidad y Claridad
La documentación debe ser accesible para diferentes niveles de experiencia y clara en su comunicación. Debe evitar jerga innecesaria y explicar conceptos complejos de manera comprensible.

### Estándares de Documentación

#### Estructura de Documentos
- Título claro y descriptivo
- Resumen ejecutivo
- Contenido organizado en secciones
- Conclusión o próximos pasos
- Referencias relevantes

#### Estilo de Escritura
- Lenguaje claro y directo
- Voz activa preferida
- Tono profesional pero amigable
- Consistencia en terminología
- Ortografía y gramática correctas

#### Formato y Presentación
- Uso consistente de encabezados
- Listas con viñetas o numeradas
- Código en bloques con sintaxis resaltada
- Imágenes con descripción alternativa
- Enlaces funcionales y descriptivos
